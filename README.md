# Hey, I'm Riley 👋

Founding engineer at [Pitchwits](https://pitchwits.com), where I built the whole platform solo: agentic search, multi-provider model routing, and RAG over grant and R&D funding data. Based in London.

### What I'm working on

- **Pitchwits platform**: multi-provider model routing on AWS Bedrock, pgvector RAG across seven corpora, multi-agent orchestration, an RLHF pipeline, semantic search over 150k+ organisations, and a voice onboarding flow. Most of my recent commits live here (private).
- **[Dendric](https://github.com/rileyq7/dendric)**: research-side project. A biologically-inspired memory lifecycle primitive for LLM agents. Neurotransmitter-style signal weighting, RRF retrieval, and sleep-cycle compaction.
- **Agent intent research**: studying when AI agents cross boundaries, like reading files they shouldn't, and detecting it before it happens.
- **Forge**: my coding composer, with a routing model that runs frontier models in parallel (private).
